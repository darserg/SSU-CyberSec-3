# Основные виды стрелкового вооружения военнослужащих российской армии
Для уничтожения живой силы противника в ближнем бою и для уничтожения легкобронированной техники, солдаты вооружённых сил России имеют автоматы Калашникова (АК-47, АК-74У, АК-С), пулемёты Калашникова. Данное оружие, кроме пулемётов имеет патроны 7.62 мм или 5.45 мм. Патрон бывает со стальной пулей, трассируещей пулей. 7.62-миллиметровый патрон в ближнем бою может пробить рельсу. 7.62 мм патрон со стальным наконечником - прямого воздействия. То есть, такой патрон при попадании в человека прошивает его, пробивает и разбивает кости. 5.45 миллиметровый патрон - пуля, вылетая из ствола начинает закручиваться, но хвост немного отстаёт. Такая пуля при столкновении с препятствием (например, костью), может изменить направление.

Автомат Калашникова представляет из себя деревянный или пластмассовый приклад, где имеется технологическое отверстие, куда вставляется пенал с отвёрткой и ёршиком для чистки автомата. Приклад предназначен для облегчения и упора при стрельбе. Также имеется пистолетная рукоятка с ~~курком???~~ спусковым крючком для производства выстрела. Рядом с курком находится планка для фиксации магазина, магазин ёмкостью 30 патронов. В магазине имеется технологическое отверстие, которое показывает, полностью ли заряжен магазин. Магазин предназначен для хранения и использования патронов при стрельбе. Имеется курок для производства выстрела, также имеется предохранитель с двумя видами стрельбы: АВ - автоматический и ОД - одиночный. Затворная рама и крышка ствольной коробки для предохранения от грязи возвратного механизма. Возвратная пружина для возврата и заряжания новым патроном. Имеется газовая камера, в которой скапливаются газы для производства выстрела. Имеется цевьё для того, чтобы не обжигать руки при стрельбе. Нарезной ствол, калибром 7.62 $\times$ 39. Имеется шомпол для чистки и смазки оружия. Имеется мушка для организации прицеливания, её совмещают с прицельной планкой, также имеется пламегаситель. Для переноски автомата используется ремень

Меры безопасности при обращении с оружием:
1. Не направлять оружие на людей
2. Без разрешения начальника стрельб не досылать патрон в патронник, только на огневом рубеже
3. Не направлять оружие в тыл, на животных или на людей
