# Наследование

```RUBY
class B < A
  def initialise(f=0)
    @foo = f
  end
  
  def m2 x
    @foo += x
  end
  
  def foo
    @foo
  end
end
```

`B.classs.superclass` -> A
`B.classs.superclass.class` -> Class
`B.classs.superclass.superclass` -> Object


`object.is_a?(class)` - проверка объекта `object`, является ли он объектом класса `class`

`Object` - суперкласс для всего

`object.instance_of?(class)` - проверка, является ли `object` экземпляром `class`

`object.methods` - выводит список всех доступных методов для `object`

```ruby
def mmm1 x
  x + 1
end
```

# Массивы
В ruby динамические массивы - последовательность элементов, которые записываются в квадратные скобки. К элементам массива можно обращаться по индексу. Элементы нумеруются с нуля

При обращении к несуществующему элементу будет выдано `nil`

`array.lenght` - выводит длину массива

В массиве можно обратиться к несуществующему элементу и задать ему значение. Все промежуточные значения будут заполнены `nil`


```RUBY
a = [1, 2, 3, 4, 5, 6, 6]
a[-67] # -> nil
a[-67] = 1001 # -> ошибка
```

Срезы массивов
```ruby
a[3, 5] # [4, 5, 6, 6]
a[3, 5] = 4 # [1, 2, 3, 4]

b.push 5 # b = [5]
b.push 7 # b = [5, 7]
b.pop # 7; b = [5]
b.pop # 5; b = []

b = [1, 2, 3]
b.shift # 3
b.unshift 9 # b = [9, 1, 2]
b.shift 2 # [9, 1]
b.unshift [5, 6, 7, 4] # [[5, 6, 7, 4], 3]
b.unshift (5, 6, 7, 4) # [5, 6, 7, 4, [5, 6, 7, 4], 3]
b.push (5, 6, 7, 4) # [5, 6, 7, 4, [5, 6, 7, 4], 3, 5, 6, 7, 4]

a = Array.new(4) {[1, 2, 3]} # [[1, 2, 3], [1, 2, 3], [1, 2, 3], [1, 2, 3]]
a[1][1] = 99 # [[99, 2, 3], [1, 2, 3], [1, 2, 3], [1, 2, 3]]

a = Array.new(4) { |x| x } # [0, 1, 2, 3]
a = Array.new(4) { |x| Array.new {x}} # [[], [nil], [nil, nil], [nil, nil, nil], [[], [nil], [nil, nil], [nil, nil, nil]]]

a.each { |x| print [x]; puts x } 
```



`puts` - выводит все элементы поочерёдно
`print` - выводит как цельный массив

`each` - применяет действие к каждому элементу массива
`map` - создаёт массив из результатов блоков, которые будут выполняться для каждого элемента массива

`map!` - результат возвращается и присваивается к исходному массиву

`each_with_index` - работает как `each`, только есть ещё индекс

```ruby
c = b.each_with_index { |x, i| print i; print " "; print x; print "\n" }
```

# Хэш
Хэш - набор пар "Ключ-значение". Хэш можно задать вручную

```ruby
h = {}
h[89] = 111111 # ключ - 89; значение - 111111
h[7] # -> nil
h # {89 => 111111}
h1 = {1 => 34, 6 => 89, 1111 => 986798}
h1[1] # 34
h1[2] # nil
h1[5] # nil
h1[1111] # 986798
h[11] = 784 # хэш пополнился
h1.keys # выведет массив индексов элементов кеша
h1.values # выведет массив значений элементов кеша
```

`each` работает для хеша, но работает с массивом из двух значений -  ключ и значение

```ruby title:"GPT-CODE"
h2 = {key1: 987, key2: 9879, key3: "jhghj"} 
# Ключами являются значения, начинающиеся на ":"
# Синтаксический сахар, чтобы не писать =>
```

# Диапазоны или range
```ruby
(1..56)
(1..56).class # -> Range
(1..56).to_a # Список элементов от 1 до 56
(1..56).step(5).class # -> Enumerator
(1..56).step(5).to_a # получаем список элементов enumerator
```
# Блоки
Блоки - сущность, которая не является объектом.
Блок обычно заключается в фигурные скобки.
Если тело блока многострочное, то вместо фигурных скобок следует писать `do` в начале блока и `end` в конце.

Блок можем передавать функции в качестве некоторой функции, которая может быть присуща функции (а может и не быть).

```ruby
class Foo
  def initialise(max)
    @max = max
  end
  
  def silly
    yield(4, 5) + yield(@max, @max)
  end
  
  def count base
    if base > @max
      raise "reached max"
    elseif yield base
      1
    else
      1 + (count (base + 1) {|i| yield i})
    end
  end
end

f = Foo.new(1000)

f.silly {|a, b| 2 * a - b}

f.count(10) {|i| (i * i) == (34 * i)}
```
