```lisp
`(A B ,(+ C 9) 27) ; C = 3
(A B 12 27)
```

`,@` - выражение должно генерировать список и вместо `,@expr` ставится несколько подряд идущих элементов списка, который является значением выражения

```LISP title:"Пример на ,@"
(let ((e '(A B C)))
	`(A1 B2 ,e C3))
	; (A1 A2 (A B C) C3)

(let ((l '(A B C)))
	`(A1 B2 ,@l C3))
	; (A1 B2 )
```
