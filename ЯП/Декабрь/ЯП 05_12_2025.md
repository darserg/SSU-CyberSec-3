`,@` - выражение должно генерировать список и вместо `,@expr` ставится несколько подряд идущих элементов списка, который является значением выражения

```LISP title:"Пример на ,@"
(let ((e '(A B C)))
	`(A1 B2 ,e C3))
	; (A1 A2 (A B C) C3)

(let ((l '(A (B C))))
  `(A1 B2 ,@l C3))
	; (A1 B2 A B C C3)
```

# Механизм отложенных вычислений
```
h = 25 * x + 14
При обращении к h значение вычислится
```

```sml
fun h () = 25 * x + 14 (* x - глобальная переменная, если не существует - сборки не будет, ошибка компиляции*)
h () => 64 (* Подобное выражение в haskell после вызова было бы в кэше, но не в SML *)
\() -> 25 * x + 14 (* Необходимо переделать выражение в лямбда-функцию *)
```

Замыкание - некоторой тело некоторой неименованной функции

```LISP

(NIL . (lambda () (+ (* 25 x) 14)))
```

Для того, чтобы откладывать вычисления, нужно использовать специальную функцию

```LISP
(delay (+ (* 25 x) 14))
(defmacro delay (expr)
  `(CONS NIL (lambda () ,expr)))
(setq a (delay (+ (* 25 x) 14)))
(force a) => 64 ; force получает на вход выражение, которое нужно вычислить позже
(defun force (v)
  (if (car v) (cdr v)
    (progn (setf (car v) t)
           (setf (cdr v)
           (funcall (cdr v))))))

```
