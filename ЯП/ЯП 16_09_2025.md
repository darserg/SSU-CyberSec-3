Чтобы `use` была полноценной командой, то код бы выглядел так:
```SML

```
Но обычно запись `val a =` опускают, остаётся неполная функция

```SML

```

`use` - неполное выражение, перед и после него необходима точка с запятой

Если в программном коде встречается неполная команда, её нужно выделить точкой с запятой

```SML

```

### Полиморфные функции, полиморфизм
```SML
fun f (l : 'a list) : 'a = (* функция возвращает третий элемент *)
  hd (tl (tl l) )
  
f [ 1, 2, 3, 4 ] => 3
int list
f [ 1.5, 2.5, 3.7, 4.8 ] => 3.7
real list
f [ "abc", "bca", "a", "d" ] = "a"
string list
```

```SML
fun g (l: 'a list, l': 'a list) : 'a * 'a =
  (hd l, hd l')

g ([1, 2], [5, 6]) (* 1, 5 *)
g ([1.2, 3.7], [4.3, 8.1]) (* 1.2, 4.3 *)
g ([1,2], [3.5, 7.3]) (* Ошибка *)
```


```SML
fun g (l: 'a list, l': 'b list) : 'a * 'b =
  (hd l, hd l')

g ([1, 2], [5, 6]) (* 1, 5 *)
g ([1.2, 3.7], [4.3, 8.1]) (* 1.2, 4.3 *)
g ([1,2], [3.5, 7.3]) (* 1, 3.5 *)
```

В SML имеется полиморфизм функций по типу данных

Встречается другой вид полиморфизма:

Можно использовать любой тип, для которого возможно сравнение 
```sml
fun f'' (l :  list ) :  list = (* Удаление идущих подряд дубликатов *)
  if null l then []
  else if null (tl l) then l
  else if hd l = hd (tl l) then f''(tl l)
  else hd l :: f'' (tl l)


```

```sml
(* [1, 2, 3, 4, 5] => [5, 4, 3, 2, 1] *)
(* ПЛОХО, так делать нельзя *)
fun reverse (l: 'a list) : 'a list = 
  if null l then l
  else reverse (tl l) @ [hd l]
```

Полноценного ООП не может быть без четырёх принципов ООП:
- Инкапсуляция
- Наследование
- Полиморфизм
- Абстракция

Нельзя использовать `@`, иначе - 0 баллов

```SML
fun reverse ( l : 'a list) 'a list =
  let 
    fun revHelper ( l : 'a list, acc : 'a list) : 'a list =
      if null l then acc
      else revHelper ( tl l, hd l :: acc)
  in
    revHelper (l, [ ])
  end

reverse [ 1, 2, 3 ]
```

```
reverse [1, 2, 3]
	revHelper([1, 2, 3], [])
	revHelper([2, 3], [1])
	revHelper([3], [2, 1])
	revHelper([], [3, 2, 1])
[3, 2, 1]
```

<u>Если нужно поставить элемент в конец списка один раз, можно использовать `@`</u>

# Поиск элемента в списке. Option-тип
```sml
fun search (l: 'a list, f : 'a -> bool) : 'a =
  if f ( hd l ) then hd l
  else search ( tl l, f )

fun search (l : 'a list, f : 'a -> bool) : 'a option =
  if null l then NONE
  else let val b = hd l
  in
    if f b then SOME b
    else search (tl l, f)
  end
```

```sml
int option (* опция целого типа *)
int option => NONE (* отсутствие *)
int option => SOME <значение>
			  SOME 15 : int option
```

```sml
fun max (l : 'a list, f 'a * 'a -> bool) : 'a option =
  if null l then NONE
  else let
       fun maxNonEmpty (l : 'a list) : 'a =
        if null (tl l) then hd l
        else let
          val m = maxNonEmpty (tl l)
        in
          if f (hd l, m) then m
          else hd l
        end
    in
      SOME (maxNonEmpty l)
    end
```

```
max ([5, 3, 7, 4], op < )
	SOME (maxNonEmpty [5, 3, 7, 4]) (* 5, 7 = 7 *)
	m = maxNonEmpty [3, 7, 4] (* 3, 7 = 7 *)
		m = maxNonEmpty [7, 4] (* 7, 4 = 7 *)
			m = maxNonEmpty [4]  (* 4 *)
```
