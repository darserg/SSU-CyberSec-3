$$
\begin{gathered}
f(n+k) = c_{1} f(n+k-1) + c_{2} f(n + k - 2) + \dots + c_{k} f(n) & (1) \\
x^{n+k} = c_{1} x^{n+k-1} + c_{2} x^{n + k - 2} + \dots + C_{k}
\end{gathered}
$$

Общее решение рекуррентного соотношения (1) имеет вид:
$$
f(n) = A_{1} + A_{2} + \dots + A_{p}
$$

# Производящие функции
*Определение*: 
Пусть имеется последовательность чисел $\{ a_{n} \} = a_{0}, a_{1}, a_{2}, \dots$, производящей функцией называется выражение вида: $A(t) = a_{0} + a_{1}t + a_{2} t^2 + \dots + a_{n} t^{n} + \dots = \sum_{n=0}^\infty a_{n} t^n$ - открытая форма производящей функции (ПФ). Пусть $A(t)=\sum_{n=0}^\infty a_{n} t^n$ и $B(t)$, которые задают две последовательности. Пусть $\exists C(t) = A(t) + B(t) = c_{0} + c_{1} t + c_{2}t^2 + \dots = \sum_{n=0}^\infty c_{n} t^n$ и $\forall c_{n}: c_{n} = a_{n} + b_{n}$

$A(t) + B(t) = B(t) + A(t)$
$(A(t) + B(t)) + C(t) = A(t) + (B(t) + C(t))$
Можно задать также и линейную комбинацию

Пусть имеются $A(t)$ и $B(t)$, произведением $A(t) \cdot B(t)$ называется $C(t) = A(t) \cdot B(t)=c_{0} + c_{1} + c_{2} t^2 + \dots = \sum_{n=0}^\infty c_{n} t^n$, где $c_{0} = a_{0} b_{0}$, $c_{1} = a_{0}b_{1} + b_{0} a_{1}$, $c_{2} = a_{0} b^2 + a_{1} b^1 + a_{2} b_{0}$
