# Комбинаторика разбиений
Для того, чтобы определить, сколькими способами можно определить на подмножества, связанные со множествами.

Основной метод - шары и ящики

![[Drawing 2026-03-19 12.38.26.excalidraw]]


| Ящики\Шары             | Различные                                                | Не различные                      |
| ---------------------- | -------------------------------------------------------- | --------------------------------- |
| Различные пустые       | $U(n,k) = k^n$                                           | $T(n,k)=C_{n+k-1}^{k-1}$          |
| Различные не пустые    | $U^* (n,k) = \sum_{i=0}^{k-1} (-1)^{i} C_{k}^{i}(k-1)^n$ | $T^*(n,k)=C_{n-1}^{k-1}$          |
| Не различные пустые    | $V ( n, k ) = \sum_{i=1}^{k} V^{*} (n, i)$               | $W(n,k)=\sum_{i=1}^k W^{*}(n, i)$ |
| Не различные не пустые | $V^{ * } ( n, k ) = \frac{U^{ * } ( n, k )}{ k! }$       | $W^{*} (n, k) = W(n - k, k)$      |


*Пример 1*:
Нужно раздать 6 шаров 3 детям, могут быть без шаров.
$U(6,3)=3^6 = 729$
**Ответ**: 729

*Пример 2*:
Нужно раздать 6 шаров 3 детям, не могут быть без шаров
$U^{*} (6,3) = 3^6 - C^{1}_{3}\cdot 2^6 + C_{3}^2 \cdot 1^6 = 540$
**Ответ**: 540
Чередование знаков

$U^{*}(n,k)=k^n - C_{k}^{1}\cdot(k-1)^{n} + C_{k}^{2}\cdot (k-2)^{n} - C_{k}^{3} \cdot (k-3)^n + \dots + (-1)^{k-1}\cdot  C_{k}^{k-1}(k-(k-1))^{n}$

*Пример 3*:
Даны 6 одинаковых карандашей, сколькими способами можно распределить их между тремя детьми?
$T(6,3)=C_{8}^{2}=28$
**Ответ**: 28

*Пример 4*:
Даны 6 одинаковых карандашей, сколькими способами можно распределить их между тремя детьми? У всех точно есть карандаши
$T^{*}(6,3) = 10$
**Ответ**: 10

*Пример 5*:
Имеется 6 игрушек, сколькими способами можно разложить их на 3 подарка? Ящики не пустые
$V^{ * } ( 6, 3 ) = \frac{U^{*} ( 6, 3 )}{ 3! } = 90$
**Ответ**: 90

*Пример 6*:
Имеется 6 игрушек, сколькими способами можно разложить их на 3 подарка? Подарки могут быть пустые
$V ( 6, 3 ) = \sum_{i=1}^{3} V^{*} (6, i) = V^{*} (6, 1) + V^{*} (6, 2) + V^{*} (6, 3) = 122$
**Ответ**: 120

*Пример 7*:
Сколькими способами можно разложить 25 одинаковых шаров по 6 различным ящикам так, чтобы в каждом ящике оказалось не менее 2 шаров?
$n=25$, $n_{1}=25-6\cdot 2$, где $n_{1}$ - после того, как в каждый ящик убрали по 2 ящика
$T(n_{1}, k) = C_{13+6-1}^{6-1} = \frac{18!}{5!(18-5)!}= 8568$
**Ответ**: 8568
