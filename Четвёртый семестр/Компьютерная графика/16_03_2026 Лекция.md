Допустим, что нужно отрисовать кривые линии, которые нужно отсечь
Для того, чтобы это сделать, нужно найти границы области и отсечь по этой области. Для этого используется алгоритм ...
Изначально есть размер окна и координаты рисунка. 
`minX`, `minY`, `maxX`, `maxY`

Само по себе окно - пересечение двух параллельных прямых. 

Левая нижняя точка - `1 0 0 1`
Правая нижняя точка - `1 1 0 0`
Внутри окна - `0 0 0 0`
И тд
