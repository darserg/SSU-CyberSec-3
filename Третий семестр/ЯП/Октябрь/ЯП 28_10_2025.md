# Ленивые вычисления
Ленивые вычисления позволяют рассмотреть такую модель программирования, когда списки являются интерфейсами и основными структурами данных

## Слабая головная нормальная форма
Форма значения, которая вычислена с точностью до конструктора

Если есть конструкторы в смысле `data` в `Haskell`

```SML
datatype 

'a list
(* конструкторы списка :: [] *)
```

```haskell
data

lst
-- : [] - конктрукторы списка
```

## Термины
> **Конструктор** - функция, которая выдаёт значение какого-то типа данных
  **Селектор** - функция, которая извлекает составляющую из структуры (геттер)
  **Сеттер** - функция, которая позволяет изменить в заданной структуре данных одно из составляющих на другое значение

## Бесконечные списки
```haskell title:Haskell
ones = 1 : ones
- head ones
  1 : thunk  
  -- Поесле выполнения 5 строки (1 : thunk)
- head (tail ones)
  1 : thunk
- head (tail (tail ones))
  1 : thunk
ones = [1, 1 ..]
```

```SML title:SML
fun ones() = 1 :: ones()

hd (ones ())
(* Выдаст ошибку *)
```

```haskell title:Haskell 
nat = 1 : ones
nat = 1 : (map (1+) nat)
nat = 1 : zipWith (+) nat ones
nat = [1 ..]
-- 1 2 3 4 5 ...
-- 1 1 1 1 1 ...
-- -------------
-- 2 3 4 5 6 ...

-- fact -> 1, 1, 2, 6, 24, 120, ...
fact = 1 : zipWith (*) nat fact
```

```Haskell title:HaskellFibonnachi
-- fibb
-- fibb -> 0, 1, 1, 2, 3, 5, 8, 13, ...
--         1, 1, 2, 3, 5, 8, 13, 21
--         1, 2, 3, 5, 8, 13, 21, 34

fibb = 0 : 1 : zipWith (+) fibb fibTail
where fibTail = tail fib
```

```Haskell title:Haskell
[3, 10 .. 15]
-- [3, 10], шаг - разность между первым и вторым элементом
[3 ..]
-- [3, 4, 5, 6, ...]
```

```Haskell title:Haskell_take
take n l -- n - целое неотрицательное число, l - список
take 0 _ = []
take _ [] = []
take n (x : xs) = x : take (n-1) xs
```


```Haskell title:Haskel_drop
drop 0 l = l
drop n [] = [] -- -> может быть сообщение об ошибке
drop n (_ : xs) = drop (n-1) xs
```

```haskell title:Пример_take
fibb = 0 : 1 : zipWith (+) fibb fibTail
where fibTail  tail fib

take 0 _ = []
take _ [] = []
take n (x : xs) = x : take (n-1) xs

- take 4 fibb
  -- fibb 0 : 1 : 1 : 2
  -- fibTail 1 : 1: 2
  -- zipWith = 1 : 2
  -- 0 : 1 : 1 : 2 : []
  -- [0, 1, 1, 2]
```
## Создание абстракции
```SML title:SML_MODULE
datatype vector = VECT of real * real * real

fun vec v = VECT v

fun xCoor (VECT (x, _, _)) = x

fun add (v1, v2) =
  vec (
    xCoor v1 + xCoor v2,
    yCoor v1 + yCoor v2,
    zCoor v1 + zCoor v2
  )
```

Под новым типом данных - вектором, будет пониматься то, что создано с помощью функции `vec`

По сути, **чтобы создать абстракцию**, необходимо:
1. Описать набор конструкторов (для нескольких подразумеваемых конструкторов, например, комплексные числа)
2. Набор селекторов


> Создавая абстракцию, мы переходим на новый уровень абстракции


> Барьер абстракции обеспечивается набором конструкторов, геттеров и сеттеров
