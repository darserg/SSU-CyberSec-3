# Динамическое и лексическое связывание в LISP
```CPP
int i = 3;

void f() {
	cout << i;
}

void g() {
	int i = 4;
	f();
}

int main() {
	g(); // OUTPUT: 3, пример лексического связывания
}
```

**Лексическое связывание** - сопоставление переменных с их значением происходит по мере описания лексики.

**Динамическое связывание** - связывание, которое происходит в порядке выполнения программы.

Языки со статической типизацией тяжело работают с динамическим связыванием.

Тип связывания зависит от языка программирования; Наиболее популярное связывание - лексическое; В `PERL` и `LISP` есть выбор, как связывать переменную.

```lisp
(setq x 0)

(defun f ()
  (let ((x 2))
    (print x))
  (print x))


(defun g ()
  (let ((x 1))
    (f))) ; x = 0; Статическое связывание


(defun g1 ()
  (let ((x 1))
    (declare (special x)) ; x = 1; Динамическое связывание
    (f))) 
```

`declare` говорит, что связывание становится динамическим

Чистое ООП

Объект может реагировать на какие-то сообщения. Реакция может быть разной - смена состояния объекта, а может заставить объект отправлять сообщения другим объектам


Вся программа предполагает описание набора объектов и описание сообщения одному из основных объектов. После этого объект может менять своё внутреннее состояние, а может отсылать сообщение другим объектам.

Объект может иметь внутреннее состояние, которое может менять. 

Чистое ООП предполагает, что все сущности - объекты. Какую бы сущность мы не использовали - это объект, принадлежащий другому классу.
