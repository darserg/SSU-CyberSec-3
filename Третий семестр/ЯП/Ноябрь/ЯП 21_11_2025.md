Дополнительная лекция

В LISP типы данных определяются во время выполнения программы, типы данных не описываются. Функция может принимать любой тип данных, но может отвергнуть какой-то тип данных, понятие сигнатуры функции отсутствует.

Одной и той же переменной можно присваивать значения разных типов

```sml
val a = 3.56
val a = "str"
```

```lisp
(setq a 15) ; изначально в a хранится значение 15
(setq a "str") ; старую ссылку затёрли, установили новую - на значение "str"

(15 3.14 (3 A "str"))
```

`CONS` - тип данных, который представляет собой две ячейки памяти - `CAR` и `CDR`

```LISP
(CONS арг1 арг2)
```

```lisp
(set b (+ a c))
```

Программа с динамической типизацией должна уметь определять, какого типа значение

Все значения должны сопровождаться дескрипторами

Так как нет предварительного описания типов, неизвестно, какого типа придёт параметр функции

# Предикат
Предикат возвращает истину или ложь, ложь - `NIL` или `()`; истина - `T`
```lisp
(numberp a) ; проверка, является ли number 
(listp a) ; проверка, является ли list
(consp a) ; проверка, является ли cons
(atom a)
```

Атом - это не отрицание `listp`

# Определение функции
```lisp title:"Функции в LISP"
(defum имя (параметры) тело)
(progn арг1 арг2 арг3 ... аргN) ; последовательно вычисляет аргументы, если приводит к побочному эффекту - эффект остаётся до следующего элемента, результат функции - результат значение последнего аргумента
(progn (setq a 15) (setq b (+ a 3)) (setq c 3.7) (* b c)) ; результат - 18 * 3.7 
```

Для того, чтобы при вычислении значения ничего не переопределялось, необходимо использовать `let`

```LISP
(let ((имя значение) (имя значение) (..)) тело let)
```

Значения локальных параметров вычисляются независимо друг от друга

В теле `let` можно выполнять несколько различных операций, как `progn`

```lisp
(let ((a 15)
      (b (+ a 3))
      (c 7. 7))
      (* b c))
```

Отличие `let` и `let*` - в `let*` параметры определяются последовательно

## Неименованные функции
```lisp
(lambda (параметры) тело) ; тело - неявный progn
(имя1 имя2 имя3 &optional (имя4 1) (имя5 NIL)) ; optinal-парамеры
(&rest имяk) ; значение всех параметров объединяется и записывается в параметр rest 
```

```LISP
(defun rev (l &optional acc)
  (if (null l) acc
      (rev (cdr l) (cons (car l) acc))))
; определение фукнции reverse на LISP
```

```lisp
(defun f (a &optional (b 3) &rest c))

(f 15 7)
(f 15 7 25 14 29 19)

; примеры rest-функцй
(+) -> 0
(+) -> 1
(+ 3 2 1 4 5) -> 15
(-) - ошибка
(- 3) -> -3
(- a b c d e f) -> a - b - c - d - e - f
```

$(/ \space a \space b \space c \space d) = \frac{a}{b \cdot c \cdot d}$

```lisp
(f &key (a 15)) ; ключевые аргументы
(f :a 25) ; можно поменять порядок ввода параметров
```

`rest` - функция может иметь сколько угодно параметров

Есть ещё специальные параметры -  `&aux` - вспомогательные параметры, которые не являются параметрами функции (объявление локальных переменных)

```LISP title:"&aux"
(defun f (a &aux (b (car a))) (c (cdr a)))
```

```lisp title:"eval"
(eval выражение) ;  невычисленное выражение на LISP 
(eval '(+ 2 3 4 5 1))
```
