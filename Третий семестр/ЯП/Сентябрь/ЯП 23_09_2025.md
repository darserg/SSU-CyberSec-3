# Контейнеры и объявление собственных типов данных
**Контейнер** - структура, которая содержит в себе другие данные

```SML
int list (* Один из примеров контеёнера *)
real option (* Тоже контейнер, может содержать значение *)
```

## Собственные типы данных. Способы создания
### Определение синонимов типов данных
```SML
date = (int * int * int)
```

`date` в данном случае - синоним, можно записать короткий синоним вместо длинного наименования

```SML
type 'a person = { name : string, age : int, num : int, salary : real, : 'a list }
v : int person (* Пример реализации *)
```

Синонимы неразличимы для программы, заменяют одни имена другими

### Определение контейнеров
```SML
datatype color = RED | BLUE | WHITE | ORANGE | BLACK | RGB of int * int * int
val a = RED
val c = RGB (3, 15, 255)
```

`color` - имя типа, в правой части записываются конструкторы элементов этого типа
`datatype` определяет новый тип данных


```SML
datatype bool = true | false
```

```SML
datatype 'a myList = NIL
                | CONS of 'a * 'a myList

val l = NIL
val l1 = CONS ( 3, CONS ( 2, CONS ( 15, NIL)))
```

## Механизм сопоставления с шаблоном или Разложение по шаблону
```SML
d : date
val (day, month, year) = d
val (a1, a2, a3) = (b1, b2, b3)
```

Шаблон может содержать в себе
1. Конструкторы
2. Идентификаторы
3. Джокер (wildcard \_)
4. `<шаблон> as` 


### Использование джокера
```SML
val SOME a = SOME 15
val (_, month, year) = d
val (day, month, year) = d
```

```SML
val (_, _, _::_::x::_) = a2
val _::_::(_,y)::_=a1
```


### Работа с case
```SML
case <выражение>
  of <шаблон_1> => результат_1
  | <шаблон_2> => результат_2
  ...
  | <шаблон_n> => результат_n
```


```SML
case a2
  of (_, _, _::_::x::_) => выражение
  | _ => raise Match (* Выбрасывает системную ошибку Match *)
```

```SML
case (a2, a1)
  of ((_, _, _::_::x::_), _::_::(_, y)::_) =>
  | _ => raise Match
```


```SML
fun f (l : int list) : int list =
  case l
    of x :: ( xs as ( x' :: _ )) => x + x' :: f xs
    | _ => []
```

```SML
fun f ( d : date ) : ...
  val f = fn : int * int * int
```

Все ранее описанные функции - функции одного аргумента


```SML
fun имя шаблон1 = выражение1
  | имя шаблон2 = выражение2
  
fun f (x :: (xs as (x' :: _))) = x+x' :: fs xs
  | f _ = [] 
```

# Автоматическое определение типа
```SML
fun f (....) = x + x' :: f ...
  | f _ = []
```

`+ = int * int -> int`
Автоматически определяются типы данных для функции, `int list -> int list`


```SML
fun f (x : real :: xs as ) = x + x' :: f ...
  | f _ = []
```

Функция автоматически превращается в `real list -> real list`
