#ProgrammingLanguages #RUBY 

Если вы описываете класс, вы описали нечто подобное типу данных, описывается структура данных

Разные объекты - разные представители одного и того же класса

Переменная состояния присуща только объекту

При изменении объекта изменяется только состояние объекта, не изменяется сам объект

Существуют статические переменные - `@@name` - переменная, которая относится ко всему классу, в отличие от `@name` - переменная, которая относится к объекту класса

Метод класса - метод, который запускается от класса.

```ruby

  end
  
  def m1
    a = 66
    @foo = 45 + a
    self
  end
  
  def m5
    @foo + foo

class B < A # Методы класса A наследуются в класс B
```

Переменная без `@` - локальная переменная, нет доступа извне

`self` может быть использовано для того, чтобы обратиться к другим полям в методе

Диспетчерезация - когда запускаем метод, диспетчеризация определяет, какому методу передавать управление

В `Ruby` - динамическая диспетчеризация 

`public` - доступ к методу/полю класса есть извне
`private` - доступ закрыт

```ruby
class B
  private
  
  def foo
    @foo
  end
  
  def foo = n
    @foo = n
  end
  
  def m1 x
    @foo += x
  end
  
  public  
  
  def m2
    m1
    @foo -= m3
  end
  
  def m3 
    15
  end
end

class B < A

    m2 * m3
  end
  
  def m3

  end

```

`protected` - можно описывать разный уровень доступа

```ruby
class A
  def foo           # Геттер (ридер)
    @foo
  end
  
  def foo = x       # Сеттер 
    @foo = x
  end
  
  public
  
  def m1 x
    @foo += x
  end
  
  private
  
  def m2
    m1
    @foo -= m3
  end
  
  protected
  
  def m3 
    72
  end
end

class B < A
  def m1
    m2 * m3
  end
  
  def m5
    m2 + 3
  end
  
  def m6
    m3 + 4
  end
  
  def m7
    B.new.m1 + 2 
  end
  
  def m8  # Выдаёт ошибку из-за нарушения доступа
    B.new.m2 + 3
  end
end
```

Методы protected доступны наследнику в любом виде. Методы private - недоступны.

`private` и `protected` доступны только самому классу и/или его наследнику
