# Генераторы списков
$$
\{ x \space {\Huge |} \space \text{условие} \} - \text{задание множества в математике}
$$
$$
\{ (x, y) \space {\Huge |} \space 0 \leq x \leq 5, 7 \leq y \leq 18, y - x = 3 \}
$$
$\in \space \Leftrightarrow$ `<-`

```Haskell
[(x, y) | x <- [0..5], y <- [7..18], y - x == 3]
[(4, 7), (5, 8)] -- переберутся все элементы для x и все элементы для y
```

`<-` перебирает все варианты из последовательности

`$` - инфиксная операция
`выр1 $ выр2 $ выр4 $ выр4` - выполняется справа налево, эта операция *ничего не делает* (операция применения). Пример использования `f $ a`, `$` имеет самый низкий приоритет среди всех операций

```haskell

```
