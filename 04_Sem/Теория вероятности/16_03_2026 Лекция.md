# Аксиоматика Колмодурова

Рассмотрим $\Omega$ - множество произвольной природы.
$f$ - $\sigma$-алгебра на $\Omega$.

Рассмотрим фукнцию $p: f\to \mathbb{R}$

Пусть $p$ удовлетворяет свойствам:
1. $p(\Omega) = 1$
2. $p(a) \geq 0 \forall A \in f$
3. Счётно-аддитивность $add$ - сумма. Если $\{ A_{i} \}_{i=1}^\infty$ таких что $A_{i}A_{j} = \emptyset$, то $p(\cup_{i=1}^\infty A_{i}) = \sum_{i=1}^\infty p(A_{i})$

$$
\{ \sigma, f, p \} \text{ называется вероятностным пространством}
$$

*Определение*:
Если $AB=\emptyset$, то говорят, что $A$ и $B$ несовместны

$p$ называется вероятностной мерой

Свойства вероятностной меры:
1. $p(\emptyset) = 0$
   **Доказательство**:
   Справедливо представление: $\emptyset = \emptyset \cup \dots \cup \emptyset$ с бесконечным множеством пересечений. Можно ввести обозначение: Рассмотрим $\{ A_{i} \}_{i=1}^\emptyset, A_{i} = \emptyset$, $p(\emptyset) \xRightarrow{A_{i} \in f, \forall i, j: A_{i} A_{j} = \emptyset} \sum_{i=1}^\infty p(A_{i})$. Обозначим $p(\emptyset)=x$ $\implies$ $x = \sum_{i=1}^\infty x \implies x=0$
2. Свойство конечной аддитивности $A_{1}\dots A_{n}$ $\forall i \in \{ 1\dots n \} A_{i} \in f,$ $p(\cup_{i=1}^n A_{i}) = \sum_{i=1}^\infty p(A_{i})$
   **Доказательство**:
   Пусть $A_{i} = \emptyset, \forall i > n; \{ A_{i} \}_{i=1}^\infty$ - последовательность элементов $f$ (попарно несовместных). $p(\cup_{i=1}^\infty A_{i}) = p(\cup_{i=1}^\infty A_{i}) = \sum_{i=1}^\infty p(A_{i}) + \sum_{i = n + 1}^\infty 0$
3. $p(\bar{A})=1-p(A)$
   **Доказательство**:
   Справедливо представление $\Omega = A + \bar{A}$ (слагаемые несовместны). $1 = p(\Omega) = p(A + \bar{A}) = p(A) + p(\bar{A})$
4. Свойство монотонности. Если $A \subset B \implies p(A) \leq p(B)$
   ![[Drawing 2026-03-16 12.48.00.excalidraw]]
   **Доказательство**:
   $B = A + \bar{A} \cdot B$ (слагаемые несовместны). $p(B) = p(A) + p(\bar{A}B)$
5. $0 \leq p(A) \leq 1$
   **Доказательство**:
   $\emptyset \subset A \subset \Omega \implies$ $p(\emptyset) \leq p(A) \leq p(\Omega) \implies 0 \leq p(A) \leq 1$
6. Формула сложения для двух событий
   $p(A+B)=p(A)+p(B)-p(A\cdot B)$
   **Доказательство**:
   ![[Drawing 2026-03-16 12.53.47.excalidraw]]
   Справедливы 2 представления:
   $A + B = A + \bar{A}B$  $B = A\cdot B + \bar{A}\cdot B$
   Можем использовать аддитивность:
   $p(A + B) = p(A) + p(\bar{A}B)$
   $p(B) = P(A\cdot B) + p(\bar{A}\cdot B)$
   $p(A + B) = p(A) + p(B) - p(A \cdot B)$
7. Формулы для вероятности суммы произвольного числа событий:
	1. Если $A_{i}$ несовместные, формула известна из свойства $2$
	2. Если $A_{i}$ не обязательно совместные:
		1. $P(A_{1} + \dots + A_{n})=1-P(\bar{A}_{1} \dots\bar{A}_{n})$
		2. Обобщение формулы из свойства 6: 
		   $P(\cup_{i=1}^\infty A_{i}) = \sum_{i=1}^n p(A_{i}) - \sum_{i, j = 1; i \neq j}^n p(A_{i}A_{j}) + \sum_{i, j, k = 1}^n p(A_{i}A_{j}A_{k}) + \dots + (-1)^k \sum_{i_{1}\dots i_{k}=1; i_{1}\neq i_{2}\neq i_{k}}^n P(A_{i_{1}} \dots A_{i_{k}}) + \dots + (-1)^n p(A_{1}\dots A_{n})$
		   **Доказательство**:
		   ПО ММИ:
		   Для $n=2$ доказано (свойство 6):
		   Допустим, для произвольного $n-1$ доказано
		   $p(\cup_{i=1}^n A_{i}) = p(\cup_{i=1}^{n-1}A_{1}+A_{n}) = p(\cup_{i=1}^{n-1} A_{i}) + p(A_{n})-p((\cup_{i=1}^n A_{i})A_{n})$
		   Так как для $n-1$ предположение истинно, то в $\alpha$ появится, как слагаемое, множество вероятностей с нужными знаками (все, что не содержат $A_{n}$)
		   Рассмотрим $\gamma$ $p((\cup_{i=1}^n-1A_{i})A_{n}) = p\left( \cup_{i=1}^{n-1} p(A_{i}A_{n}) \right) \implies$ в $\gamma$ появятся все вероятности $A_{n}$ (пары, тройки и т.д.), а нужный знак достигается при помощи $(-1)^n$
8. $p(\cup_{i=1}^n A_{i}) \leq \sum_{i=1}^n p(A_{i})$
   **Доказательство**:
   $\begin{array}lA_{1} & B_{1} = A_{1} \\ A_{2} & B_{2} = A_{2} \setminus A_{1} \\ A_{3} & B_{3} = A_{3} \setminus A_{1} + A_{2} \\ \dots \\ A_{n} & B_{n} = A_{n} \setminus A_{1} +\dots + A_{n-1} \end{array}$
   $B_{i}$ попарно несовместны. $p(\cup_{i=1}^n A_{i}) = p(\cup_{i=1}^n B_{i}) = \sum_{i=1}^n p(B_{i})$ $B_{i} \subset A_{i}$ $\implies$ $P(B_i) \leq p(A_{i})$ 
9. Свойство непрерывности вероятностной меры
   Рассмотрим $\{ A_{i} \}_{i=1}^n$ $\forall i: A_{i} \in f$. Предположим $\forall i A_{i} \supset A_{i+1}$ $\cap_{i=1}^\infty A_{i} = \emptyset$
   Тогда $p(A_{i}) \xrightarrow[i\to \infty]{} 0$
   **Доказательство**:
   $(1)\quad A_{1} = A_{1} \cdot \bar{A}_{2} + A_{2} \cdot \bar{A}_{3} + A_{3} \cdot \bar{A}_{4} + \dots$
   $(2) \quad A_{k} = A_{1}\cdot \bar{A}_{2} + A_{2} \cdot \bar{A}_{3} + \dots + A_{k}$ $k$ - фиксированное.
   Слагаемые совместны. 
   $p(A_{1}) = \sum_{i=1}^n p(A_{i}\bar{A}_{i=1})$
   $p(A_{1}) = \boxed{\sum_{i=1}^k-1 p(A_{i} \bar{A}_{i+1}) + p(A_{k})}$
   $\lim_{ k \to \infty } p(A_{k}) = 0$


**Следствие 1**: (Расширяющиеся ворота)
Пусть $\forall i$ $A_{i} \subset A_{i+1}$ $\cup_{i=1}^\infty A_{i} = \Omega$
Тогда $\lim_{ i \to \infty } p(A_{i}) = 1$
*Доказательство*:
Осуществляется рассмотрением событий $\{ \bar{A}_{i} \}$



**Следствие 2, 3**:
Предположим, что воронка сужается или расширяется до некоторого события $A$
Тогда $\lim_{ i \to \infty } P(A_{i}) = p(A)$
