# Hello World на FastAPI


```python title:"main.py"
import asyncio  
import uvicorn  
  
from fastapi import FastAPI  
from starlette.middleware.cors import CORSMiddleware  
  
  
app = FastAPI(root_path="/api/v1")  
app.add_middleware(  
    CORSMiddleware, # type: ignore  
    allow_origins=["*"],  
    allow_credentials=True,  
    allow_methods=["*"],  
    allow_headers=["*"],  
)  
  
  
async def run() -> None:  
    config = uvicorn.Config("main:app", host="0.0.0.0", port=8000, reload=False)  
    server = uvicorn.Server(config=config)  
    tasks = (  
        asyncio.create_task(server.serve()),  
    )  
	
    await asyncio.wait(tasks, return_when=asyncio.FIRST_COMPLETED)  
  
  
if __name__ == "__main__":  
    loop = asyncio.get_event_loop()  
    loop.run_until_complete(run())
```

## Импорты
`fastapi` - ну, соответственно, сам `fastapi`
`starlette` - движок, на котором работает `fastapi`
`asyncio` - встроенная в Python библиотека для написания асинхронного кода
`uvicorn` - сервер, на котором мы будем запускать наше приложение на `fastAPI`
## Middleware
Когда есть какое-либо приложение (бэкенд). У него есть API (ручки), которые сидят и слушают запросы от фронта. При отправке запроса `middleware` - это то, что выполняется до того, как попасть в API, как правило применяется для обработки запросов.

В нашем случае мы задаём в `MiddleWare` белые списки, с которых наше приложение может принимать запросы - `allow_origin`, `allow_credential` - возможность задать пароль и логин, `allow_methods` - допустимые методы из REST, `allow_headers` - допустимые заголовки запросов, в которых могут находиться метаданные и логины/пароли. 

## Как запускать приложения
В отличие от Django, наше приложение не знает, как ему самостоятельно запускаться
Существует конфигурация приложения, через которую нужно запускать наш проект.

## Функции
`run` - асинхронная функция, которая запускает наше приложение. 
В этой функции мы задаём конфиг для `uvicorn`. 
```python
async def run() -> None:  
    config = uvicorn.Config("main:app", host="0.0.0.0", port=8000, reload=False)  
    server = uvicorn.Server(config=config)  
    tasks = (  
        asyncio.create_task(server.serve()),  
    )  
	
    await asyncio.wait(tasks, return_when=asyncio.FIRST_COMPLETED)  
  
```

Наше приложение называется `main`, задаём, что это именно приложение через `:app`. 
`host` - ip-адрес нашего приложения, `port` - порт для подключения к нашему приложению в `localhost`.
`reload=False` - чтобы наше приложение не перезагружалось. 
Для работы нашего приложения нам нужно обернуть наше приложение в асинхронную задачу. 


`localhost` - локальный ip-адрес в сети (`127.0.0.1`, `127.0.0.2` и тд). 


Переход на IP-V6 на данный момент недоступен, так как это слишком дорого (нет обратной совместимости с IP-V4).

## Точка входа в программу
Точка входа в программу реализована через "магические имена". 

"Магическое имя" `__name__` - точка входа в программу.
Через `loop` мы взываем `event_loop` в этом `event_loop` мы вызываем нашу асинхронную `run`.

## Встроенное API в fastAPI
В `FastAPI` есть встроенный API для `Swagger`, который является встроенной документацией с информацией о нашем приложении.
В `Swagger` будут перечислены все возможные API на нашем приложении, записаны также все `endpoint` приложения и все возможные запросы.

`Swagger` доступен в `ip:port/docs`
