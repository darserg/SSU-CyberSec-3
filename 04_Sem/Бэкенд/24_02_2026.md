# База данных и подключение к ней
Почему будем работать с Docker?
Каждый контейнер - свой маленький Linux, в котором установлены определённые версии языка и библиотеки и это приложение можно упаковать в контейнер, который можно запустить где угодно. 
Docker позволяет управлять ресурсами приложения, к примеру, ограничить объем памяти. 

В Github-репозитории добавлена валидация моделей и обработка ошибок. 

## SQLite
SQLite встроена в Django сразу, поэтому в курсе представлена именно она.
Вообще можно использовать любую БД, но не будет работать Django ORM.

В FastAPI нет встроенной БД, что одновременно и плюс и минус.
Хотя в FastAPI нет почти ничего встроенного, кроме Swagger и Pydantic, который устанавливается сразу с FastAPI. 

## Рассмотрим вариант с SQLite.
Что такое ORM? Использование БД с использованием абстракции, в которой на Python таблица описана в виде класса. 
С разными SQL-базами могут быть разные диалекты. 
ORM позволяет на этапе подключения базы выбирать диалект, запросы будут переписываться автоматически под разные БД. 
Самое популярное, что можно использовать с любой БД - `SQLAlchemy`. 
Обычно БД - отдельное приложение, а SQLite - файлик на сервере. 

### Запросы на чистом SQL
Четыре базовые операции - `CRUD`-операции:
`SELECT` - получить данные
`UPDATE` - обновить данные
`DELETE` - удалить данные
`INSERT INTO` - вставить данные

---

С `SQLITE` есть проблема. Там отсутствует операция `UPDATE`, там есть другая функция, про которую поговорим позже.
Допустим, нам нужно добавить столбец в таблице, тогда ORM кладёт данные в сторону, удаляет старую таблицу, создаёт новую с новым столбцом и какими-то значениями по умолчанию. 

Для просмотра БД можно использовать DB Browser.
