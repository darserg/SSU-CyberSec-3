Это память, с которой процессор может работать напрямую

**Вторичная память** - для длительного хранения

Последовательность команд осуществляется устройством управления

Архитектура фон неймона

Внешняя коммуникационная система нужна для того, чтобы подключать сторонние устройства

**Интерфейс** - совокупность шин для передачи сигналов между ЭВМ

Концепция машины с хранимой в памяти программой
Программа - "упорядоченная последовательность команд, подлежащих обработке"

# Доклад 2
### Подготовительный этап
На предварительном этапе программа загружается в оперативную память и в процессор, соединяется *системной магистралью*

*Счётчик команд* - после выполнения одной команды счётчик переключается на следующую, команды выполняются последовательно

### Первый этап
ЦП проверяет адрес, отправляет команду на выборку

### Второй этап
Содержимое ячейки в ОЗУ, отправляет сигнал на ЦП для определения того, в памяти ли находятся значения

### Третий этап
Операнды загружаются в регистр команд. Поступляет в УУ (управляющее устройство) для выполнения, код операции говорит о том, что сделать, адресная часть - с чем делать

### Четвёртый этап
Считывание адресов операндов из ОП (оперативной памяти)

### Пятый этап
Считывание самих операндов из ОП, в АЛУ объект для операции

### Шестой этап
АЛУ начинает выполнять операцию, где одно из чисел берётся из аккумулятора, второе - загружается из ОП

*Аккумулятор* - может храниться результат операции

### Седьмой этап
Отправляется адрес ячейки, где будет ответ, сам ответ (записывается в ОП)

### Восьмой этап
Можно загружать следующие команды


Регистр признаков - предназначен для фиксации признаков и передачи их в АЛУ

## Элементы и узлы ЭВМ
*Процессор* - узел, в задачи которого входит выполнение кода из ОП

В настоящее время процессор = микропроцессор, который может содержать ещё и кэш память и другие узлы, процессору помогают сопроцессоры
