# Списки
Списки в `Python` `mutable` или же изменяемая структура
## Создание списка
```python
list_1= []
list_2 = list()
# List_1 = List_2.
```

## Распаковка списка по нескольким переменным
```python
any_sequence = [1, 2, 3]

first, second, third = any_sequence

print(first)
print(second)
print(third)

# Список при этом не изменился.
```


## Сортировка списков
### Сортировка без изменения старого списка
```python
list = [5, 3, 1]
list_1 = sorted(list)
```
### Сортировка с изменением старого списка
```python
list = [5, 3, 2]
list.sort()
```
## Создание новых списков
```python
list_1 = list_2 = [1, 2, 3, 4] # Не создаётся новый объект.
list_copy = copy(list_1) # Создаётся новый объект.
```

# Кортеж

# Функции
*Функция* - возвращает значение
*Процедура* - не возвращает значение
## Типы передачи данных в функцию
#### Передача аргументов
В функцию передаётся переменная в качестве аргумента

#### Передача по ссылке
Передаётся адрес переменной

#### Передача по указателю
Передаётся адрес переменной + можно производить операции

## Реализация передачи данных в Python
```python
def plus_one(number):
	number.append(4)
	print("New list=", number)

number = [1, 2, 3]
plus_one(number)
print(number) # Внешний список изменился, передача по ссылке.
# Если в функцию передать число, то внешнее число не изменится.
```

##  Возвращение нескольких значений из функции
```python
def plus_one(number, number1):
	number += 4
	number1 = number
	number1 += 5
	return number, number1 # Возвращается кортеж (number, number1).

number = 1
number = plus_one(number)
print(number) # (5, 10).
```


## Передача неопределённого количества параметров

```python
boasting("Арбуз")

```
