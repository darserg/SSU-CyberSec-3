# Классификация источников информации
Источники информации можно классифицировать по нескольким независимым признакам, один и тот же источник может быть, как двоичным, дискретным по времени, стационарным источником с памятью, поэтому существует множество различных их классификаций, при этом будем считать, что классификационные признаки независимы 

- ==По характеру выходного множества==:
	- **Дискретные источники** - выходом будет являться последовательность символов из конечного или счётного алфавита
	- **Непрерывные источники** - выходом является непрерывная случайная величина или непрерывный случайный процесс
	- **Смешанные источники** - выход содержит как дискретные, так и непрерывные компонетнты
- ==По объёму алфавита==:
	- **Конечный алфавит**  где мощность алфавита ограничена каким-либо числом
	- **Счётный алфавит** - где символы можно перенумеровать натуральными числами
	- Отдельно выделяют двоичные и n-чные алфавиты
- ==По характеру времени==:
	- **Дискретные по времени** - символы выдаются в фиксированные моменты времени
	- **Непрерывные по времени** - смена состояния источника может происходить в производные моменты времени
- ==По наличию статистической зависимости==:
	- **Источники без памяти** - символы независимо и одинаково распределены
	  Одним из самых ярких примеров является **марковский источник**, в котором зависимость будет от количества идущих символов
	- **Источники с памятью** - вероятность очередного символа зависит от предыдущих
- ==По стационарности==:
	- **Стационарные** - при этом статистические характеристики не меняются при сдвиге времени
	- **Нестационарные** - распределения и кореляционные связи меняются во времени
	  Для стационарных источников мы можем говорить об энтропийной скорости - средней энтропии в установленном режиме
- ==По эргодичности==:
	- **Эргодические источники** - среднее по времени совпадает со средним по амсамблю
	- **Неэргодические источники** - такого совпадения нет или оно не гарантируется
	Эргодичность позволяет определить вероятность реализации по одной достаточно длинной реализации
- ==По распределению символов==:
	- **Равномерные** - все символы в источнике равновероятны
	- **Неравномерны** - вероятности символов различные
- ==По размерности и структуре==:
	- **Скалярные** - каждый выходной элемент является одним символом
	- **Очные** или **векторные** - выходом является блок символов
	- **Многокомпонентные** - последовательность может состоять из разных алфавитов, так как такие источники являются взаимосвязанными источниками разной природы
- ==По детерминированности==:
	- **Детерменированные** - выход однозначно определяется состоянием источника, энтропия при этом равна нулю
	- **Случайные** - выход описывается вероятностным распределением



## Дискретный источник без памяти
*Определение 1*: Дискретный источник, который задается $A = \{ a_{1}, a_{2}, \dots, a_{n} \}$ и распределением вероятности $p(a_{i}) = p \{ X = a_{i} \}$, где $\sum_{i=1}^np(a_{i}) = 1$ будет называться дискретным источником без памяти

*Определение 2*: Источник называется дискретным источником без памяти, если порождаемые им символы независимы и будут иметь одно и то же распределение $P(X_{1} = a_{1}, \dots, X_{n} = a_{n}) = \prod_{i=1}^np(X_{i}=a_{i})$

Важным понятием источников является понятие энтропии. Энтропию источника будем обозначать $H(X) = -\sum_{i=1}^n p(a_{i}) \log p(a_{i})$. Основание логарифма может быть производным, от основания будет зависеть размерность энтропии
Основание может быть любым, от 2 и выше

При этом величина логарифмов вероятности будет называться собственной информацией символа $a_{i}$, а энтропия при этом будет тогда являться средним значением этой информации

### Свойства энтропии
1. Неотрицательность $H(X) \geq 0$, при этом 0 достигается тогда и только тогда, когда источник детерминированный 
2. Энтропия достигает максимума при равномерном распределении $H(X) \leq \log K, p(a_{i}) = \frac{1}{k}$
3. Адитивность для независимых источников. Если есть два источника $X\text{ и } Y$ и они независимы, то энтропия этих источников будет равна сумме их энтропий $H(X, Y) = H(X) + H(Y)$, в общем случае: $H(X,Y) \leq H(X) + H(Y)$
При этом в источниках важным свойством является характеристика производительности и избыточности. 
---
### Избыточность
Абсолютной избыточностью источника с алфавитом $a$ будем называть величину $R_{X}=H_{\max} - H(X)$
При этом относительной избыточностью будем называть величину $\rho=\frac{R_{x}}{H_{\max}}$
Максимальная избыточность достигается при равномерном распределении  $R_{x} = H_{\max}-H(X)=\log k - H(X)=1 - \frac{H(X)}{\log x}$

Избыточность - это величина, которая будет показывать, какая доля энтропии не используется из-за неравномерности распределения или статистической связи между символами 

Производительностю источника будем называть величину, которая будет равна произведению скорости символов в секунду на энтропию, соответственно это будет величиной единица информации, деленная на секунду

Важными для описания каждого источника является система теорем Шеннона. Как правило для каждого источника записывают два уравнения - прямую теорему Шеннона и обратную теорему Шеннона

Стоит отметить, что в теории информации в доказательствах используют системы оценок

Рассмотрим две теоремы Шеннона: 
**Прямая теорема Шеннона**: Пусть дискретный источник без памяти имеет энтропию $H(X)$, тогда $\forall \epsilon > 0\space \exists n: L_{n}$ будет удовлетворять следующему неравенству: $\frac{L_{n}}{n}\leq H(X) + \xi$ и это справедливо при достаточно больших n

**Обратная теорема Шеннона**: Пусть дискретный источник без памяти имеет энтропию $H(X)$, тогда не существует однозначно декодируемого кодирования, для которого при всех достаточно больших n выполнялось бы неравенство: $\frac{L_{n}}{n}< H(X)$.

Следует отметить, что исходя из этих теорем, энтропия $H(X)$ будет являться точной копией кодирования средней длины, к которому мы можем подойти сколь угодно близко при кодировании достаточно длинных блоков

В рамках данных теорем используется лемма о длинных кодовых словах любого однозначно декодируемого кода

**Лемма**: Для любого однозначно кодируемого двоичного кода длины $l_{1}, \dots, l_{M}$ выполняется неравенство: $\sum_{i=1}^M 2^{-l_{i}}\leq 1$

**Замечание**: Эта лемма по существу совпадает с неравенством Крафта-Макмиллана, однако, неравенство Крафта-Макмиллана объединяет в себе более широкие понятия и записывается для большего класса кодовых слов
