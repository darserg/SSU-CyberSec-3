# Модели данных
Ранние модели данных:
## Иерархическая модель данных
Самая старая, практически не используется
Это деление, модель, которая представляется в виде древовидной структуры

Свойства:
Есть корень
Узел содержит атрибуты
Исходный и зависимый узлы находятся в отношении независимый предок и потомок
Узлы добавляются вертикально и горизонтально


### Манипуляционная часть
- переход от одного дерева к другому
- переход между узлами внутри дерева
- вставка, удаление или изменение записи в указанной позиции


## Сетевая модель
Дальнейшее развитие иерархической модели. В этой модели можно использовать множественные связи для потомков - потомок может быть связан со многими предками

> Домен - множество значений атрибута
