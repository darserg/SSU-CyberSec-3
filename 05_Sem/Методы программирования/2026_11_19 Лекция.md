# Пирамиды 
В очереди с приоритетом мы рассматривали три операции: 
1. Добавить элемент
2. Посмотреть значение минимального элемента
3. Удалить минимальный элемент

Но нам для реализации потребуется 4 операции:
1. Добавить элемент
2. Посмотреть значение минимального элемента
3. Удалить минимальный элемент
4. Дано значение x, удалить **ровно один** элемент со значением x


Что значит удалить ровно один элемент? 
- В случае, если такой элемент единственный, удалится он
- В случае, если таких элементов несколько, удалится первое вхождение
- В случае если нет такого элемента, может произойти всё, что угодно

У пирамиды нет возможности обработать запрос "существует элемент или нет"

Поэтому четвёртую операцию можно делать только в том случае, если мы точно знаем, что элемент, который мы пытаемся удалить, есть в данной структуре данных

## За сколько это будет работать?
Первые три операции рассматривали на первой лекции, все работают за $O(\log n)$
Четвёртая будет также работать за $O(\log n)$, но оно будет работать **амортизировано**

##  **Амортизированная сложность операции**
- одна операция может работать дольше
- последовательность из k любых операций в пустой структуре работает за $O(k \log k)$

## Отложенное удаление
Удаляем элемент не тогда, когда пришёл запрос на его удаление, а тогда, когда это удаление влияет на другие запросы

## Решение
У нас будет BackLog запросов:
Хранятся все элементы, которые надо удалить

```python
def parent(x):
    return (x - 1) // 2


def child(x, i):
    # i = 0 - левый сын
    # i = 1 - правый сын
    return 2 * x + i + 1


class heap:
    def __init__(self):
        self.n = 0
        self.a = []

    def insert(self, x):
        self.a.append(x)
        k = self.n
        while k > 0:
            p = parent(k)
            if self.a[p] > self.a[k]:
                self.a[p], self.a[k] = self.a[k], self.a[p]
                k = p
            else:
                break
        self.n += 1

    def get(self):
        if self.n == 0:
            raise ValueError("Empty heap")
        return self.a[0]

    def pop(self):
        if self.n == 0:
            raise ValueError("Empty heap")
        self.a[0], self.a[self.n - 1] = self.a[self.n - 1], self.a[0]
        self.n -= 1
        self.a.pop()

        k = 0
        while True:
            min_child = -1
            for i in range(2):
                x = child(k, i)
                if x < self.n and (min_child == -1 or self.a[min_child] > self.a[x]):
                    min_child = x
            if min_child != -1 and self.a[k] > self.a[min_child]:
                self.a[min_child], self.a[k] = self.a[k], self.a[min_child]
                k = min_child
            else:
                break

    def empty(self):
        return self.n == 0


class heap_with_delition:
    def __init__(self):
        self.a = heap()
        self.b = heap()

    def insert(self, x):
        self.a.insert(x)

    def remove(self, x):
        self.b.insert(x)

    def fix(self):
        while (
            not self.a.empty() and not self.b.empty() and self.a.get() == self.b.get()
        ):
            self.a.pop()
            self.b.pop()

    def get(self):
        self.fix()
        return self.a.get()

    def pop(self):
        self.fix()
        return self.a.pop()

```


# HeapSort. Пирамидальная сортировка
Преимущества:
+ работает за $O(n\log n)$
+ $O(1)$ дополнительной памяти


## Фазы HeapSort
### Построение пирамиды
Изначально пирамида из 1 элемента a\[0\], потом будем добавлять в неё элементы до a\[n-1\], расширяя пирамиду

Получаем, что весь массив - пирамида
## Разрушение пирамиды
Двигаем границу между пирамидой и массивом справа налево, извлекая максимум

> [!warning] Применяют в сочетании с `quick_sort`, когда `quick_sort` работает плохо
