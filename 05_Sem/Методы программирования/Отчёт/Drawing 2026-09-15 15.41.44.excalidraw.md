Проанализировать время работы последовательности из n добавлений в конец
пустого массива

 ^6jmu2o9Z

При увеличении размера массива в два раза, нам нужно создать новый массив с длиной 2n
При этом используется создание нового массива,             O(1)
Потом записать все элементы  старого массива в новый,
для этого проходится весь старый массив циклом,            O(n)
приравнивая элементы старого массива в новый               O(1)
Добавить новый элемент в новый массив,                       O(1)
Итоговое время                                                       O(1+n*1+1+1)=O(n+3)=O(n) ^xruqEuoq

Если изначально будет пустой массив, а нужно добавить n элементов, то
Расширяем массив n раз, каждое такое увеличение выполняется последовательно, поэтому складываем время
Получаем O(n+n+...+n) = O(n) ^GxfpgqsE
