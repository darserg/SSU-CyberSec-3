Возьмём некотрое $m$, такое что $2^m\geq n$. Тогда

$$
n + \frac{n}{2} + \frac{n}{4} + \dots + \frac{n}{2^m} = \frac{n*2^m + n*2^{m-1}+\dots + n}{2^m} = n * \left( \frac{2^m}{2^m} + \frac{2^{m-1}}{2^m} + \dots + \frac{2^{0}}{2^m} \right)  =
$$
$$
= n * \left( 1 + \frac{1}{2} + \dots + \frac{1}{2^m} \right)
$$

$$
O\left( n * \left( 1 + \frac{1}{2} + \dots + \frac{1}{2^m} \right) \right) = O(n)
$$
