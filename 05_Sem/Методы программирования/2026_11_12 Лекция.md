# Пирамида и её применение
## Очереди с приоритетами/Пирамиды 
Эти два понятия обычно используют взаимозаменяемо, разница между ними заключается в терминологии
**Очередь с приоритетами** - это структура данных, которая хранит мультимножество сравнимых объектов и позволяет обрабатывать два-три типа операций:
1. Добавить элемент $O(\log n)$
2. Узнать минимальный элемент $O(1)$
3. Извлечь минимальный элемент (удалить его из структуры) $O(\log n)$


**Пирамида** - одна из внутренних реализаций очереди с приоритетами. Она представляет из себя корневое дерево, где значение в каждом узле больше либо равно значения в его родителе или в его дочерних узлах. Такую пирамиду называют минимальной (minHeap) или в каждом больше либо равно значению в дочерних узлах (maxHeap)

Довольно легко поменять минимальную и максимальные пирамиды, просто поменяв знак сравнения

## Реализация 
Нам потребуется динамический массив `vector` в `c++`, `list` в `python`, `arraylist` в `java` и тд

Нам потребуются три операции: 
1. Посмотреть/перезаписать любой элемент по индексу $O(1)$
2. Добавить в конец за $O(1)$
3. Удалить из конца за $O(1)$

Как именно мы будем использовать массив для хранения пирамиды? 
Мы будет хранить в массиве данные следующим образом: 
- Корень будет соответстовать элементу под номером 0
- Сыновья корня будут соответствовать элементам 1 и 2

Причём все слои, кроме последнего, заполнены полностью, а на последнем заполнен префикс

Это даёт три важных свойства: 
1. Высота пирамиды равна $\log_{2} (n+1)$, округлённому вверх. В пирамиде из k слоёв от $2^{k-1}$ до $2^{k}-1$ узлов
2. При добавлении элемента появляется узел с номером $n$
3. При удалении минимума появляется узел с номером $(n-1)$


## Операции просеивания
### Просеивание вверх
Начинается от узла x и действует следующим образом: 
Пока x в неправильном отношении со своим родителем, мы будем менять местами значения в x и в p(x) (родителе x) и переходить к узлу p(x)

Добавление в пирамиду: 
В конец массива добавляется новый элемент, который просеивается вверх 

```python
from random import randint

def parent(x):
    return (x - 1) // 2

def child(x, i):
    # i = 0 - левый сын
    # i = 1 - правый сын
    return 2 * x + i + 1

class heap:
    def __init__(self):
        self.n = 0
        self.a = []

    def insert(self, x):
        self.a.append(x)
        k = self.n
        while k > 0:
            p = parent(k)
            if self.a[p] > self.a[k]:
                self.a[p], self.a[k] = self.a[k], self.a[p]
                k = p
            else:
                break
        self.n += 1

    def get(self):
        if self.n == 0:
            raise ValueError("Empty heap")
        return self.a[0]

    def pop(self):
        if self.n == 0:
            raise ValueError("Empty heap")
        self.a[0], self.a[self.n-1] = self.a[self.n-1], self.a[0]
        self.n -= 1
        self.a.pop()

        k = 0
        while True:
            min_child = -1
            for i in range(2):
                x = child(k, i)
                if x < self.n and (min_child == -1 or\
                    self.a[min_child] > self.a[x]):
                    min_child = x
            if min_child != -1 and\
               self.a[k] > self.a[min_child]:
                self.a[min_child], self.a[k] =\
                self.a[k], self.a[min_child]
                k = min_child
            else:
                break

def stress():
    q = 1000
    h = heap()
    a = []
    for i in range(q):
        t = randint(1, 3)
        if t == 1:
            x = randint(1, 100)
            a.append(x)
            h.insert(x)
        else:
            if len(a) == 0:
                continue
            if t == 2:
                if min(a) != h.get():
                    print('Wrong min element')
                    exit()
            else:
                h.pop()
                a.pop(a.index(min(a)))
    print('Success')
    exit()

stress()
```
