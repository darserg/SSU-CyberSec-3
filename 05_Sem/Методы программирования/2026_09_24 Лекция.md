Сегодня мы разберём, как работает бинарный поиск и как реализовывается

В бинарном поиске (целочисленном) чаще всего рассматривается два различных сценария:
1. Посмотрев на элемент, мы можем определить, является ли он ответом, а если нет, то в какой стороне от этого элемента нужно искать дальше
   У каждой итерации есть три исхода:
	1. Нужно искать левее
	2. Нужно искать правее
	3. Итерация и есть ответ
2. Посмотрев на элемент, мы можем определить, в какой стороне искать дальше 



*Пример для первого сценария*:
Дан отсортированный массив. Проверить, есть ли в нём элемент $x$. Попав в конкретный элемент, можно сразу завершать бинарный поиск

```cpp
#include <iostream>
#include <vector>

using namespace std;

bool try_find(vector<int> &a, int x)
{
  // a - отсортированный массив
  int l = 0;
  int n = a.size();
  int r = n - 1;

  while (l <= r)
  {
    int m = l + (r - l) / 2; // наилучший вариант в C++
    
    if (a[m] == x)
      return true;
    else if (a[m] < x)
      l = m + 1;
    else
      r = m - 1;
  }

  return false;
}
```

```python
def try_find(a, x):

```


Бывают ситуации, когда мы не можем быть уверены в том, что ответ является ответом
*Пример*:
Нам нужно найти не просто какое-то значение $x$ в массиве, а первое вхождение $x$ в массиве

```cpp
int find_first(const vector<int> &a, int x)
{
  // a - отсортированный
  // если такого элемента нет, она вернёт размер массива
  int l = 0;
  int n = a.size();
  int r = n - 1;
  int ans = n;

  while (l <= r)
  {
    int m = l + (r - l) / 2;

    if (a[m] >= x)
    {
      r = m - 1;

      if (a[m] == x)
        ans = m;
    }
    else
      l = m + 1;
  }

  return ans;
}
```

## Бинарный поиск по ответу
Нам нужно придумать такую функцию $f(x)$ - верно ли, что ответ $\geq x$. Тогда функция ведёт себя следующим образом:
```
T T T T T T F F F F F
          |
```

*Пример*:
Есть $n$ катушек, в $i$ из них $a_{i}$ метров нитки. Нужно получить $k$ ниток одинаковой длины. Можно резать нитку, нельзя соединять. Какая может быть максимальная длина этих одинаковых ниток?
(Катушки не отсортированы)


```cpp
bool can(const vector<int> &a, int k, int x)
{
  // проверяющая, можно ли получить ответ >= x
  // a[i] - длина i-й катушки
  // k - количество нитей, которые мы хотим получить

  // посчитаем, сколько нитей длины x можно получить
  // проверим, если это >= k

  long long cnt = 0;

  for (auto ai : a)
    cnt += ai / x;

  return cnt >= k;
}

int solve(const vector<int> &a, int k)
{
  int ans = 0;
  int l = 1;
  int n = a.size();
  int r = n - 1;

  while (can(a, k, r))
    r *= 2;
  while (l <= r)
  {
    int m = l + (r - l) / 2;
    if (can(a, k, m))
    {
      l = m + 1;
      ans = m;
    }
    else
    {
      r = m - 1;
    }
  }

  return ans;
}
```

```python
def can(a, k, x):

#   a[i] - длина i-й катушки
#   k - количество нитей, которые мы хотим получить

#   посчитаем, сколько нитей длины x можно получить
#   проверим, если это >= k

        cnt += ai // x
    return cnt >= k

        else:
            r = m - 1
    return ans
```


## Бинарный поиск по нецелочисленным значениям
Допустим, мы хотим решить уравнение

$$
42x  \sqrt{ x } + 12 \sqrt{ x } + 37 \log_{2} x = 100
$$
при этом левая часть монотонная


```cpp
double f(double x)
{
  return 42.0 * x * sqrt(x) + 13 * sqrt(x) + 13 * log2(x);
}

double get_x()
{
  // 42 x * sqrt(x) + 13 * sqrt(x) + 37 * log2(x) = 100
  double l = 1.0;
  double r = 1e9;
  double eps = 1e-0;
  int iters = log2((r - l) / eps) + 1;

  for (int i = 0; i < iters; i++)
  {
    double m = (l + r) / 2.0;
    if (f(m) > 10)
      r = m;
    else
      l = m;
  }
  return (l + r) / 2;
}
```

```python
def get_x():
```

$$
\log_{2} \frac{r-l}{\epsilon}
$$
