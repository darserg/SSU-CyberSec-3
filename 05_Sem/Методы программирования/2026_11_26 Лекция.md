# Процесс из n отдельных шагов
Для каждого из этих шагов возникает какой-то процесс каким-то временем

Самый простой способ обработать такие события - отсортировать по убыванию моментов времени

--- 
*Пример*: Есть какая-то компания, в которой изначально 0 сотрудников и есть события какого-то вида, например, задаётся день: 
`-d_i` - в день сотрудник увольняется
`+d_i` - сотрудник устраивается на работу
`?d_i` - нужно выяснить, сколько людей работает в компании

Нужно обработать события в хронологическом порядке и вывести третий вариант события 

Обычно для событий, наступающих в один и тот же момент времени, пытаются, исходя из логики процесса, понять в каком порядке нужно их обработать 

Если у нас два события происходят в один и тот же момент и они одинаковые по типу, нам не важно в каком порядке их располагать 

- Если человек принят, в этот день он уже работает (описывает связь 2 и 3 типа событий, устанавливает, что 2 тип должен быть раньше 3)
- Если человек уволен, в этот день он ещё работает (описывает связь 1 и 3 типа событий, устанавливает, что 3 тип должен быть раньше 1)


> [!quote] Если в каком-либо языке вы собираетесь описывать свой принцип сортировки (свой компаратор), это правило должно удовлетворять следующим требованиям:
>  > [!info] **Транзитивность**. Если мы знаем, что a раньше b, b раньше c => a раньше c
>  
>  > [!info] **Антирефлексивность**. Никакой объект не должен располагаться раньше самого себя
>  
>  > [!info] **Антисимметричность**. Не должно существовать такой пары объектов, что а больше b и b больше a

Сортировка по ключам - преобразование объектов в кортеж и сравнение этих кортежей

У нас событие 3 типов, события можно выразить как кортеж из пары: `(день, тип)`
Переименуем типы событий: 
1. Добавить сотрудника
2. Спросить, сколько сейчас работает
3. Удалить сотрудника



В python, можно вызвать:
```python
a = sorted(a, key=...)
```


```python
class Event:
    def __init__(self, time, tp) -> None:
        self.time = time
        self.tp = tp


n = int(input())
events = []
for i in range(n):
    tp, time = input().split()
    if tp == "+":
        new_tp = 1
    elif tp == "?":
        new_tp = 2
    else:
        new_tp = 3

    events.append(Event(int(time), new_tp))

events = sorted(events, key=lambda e: (e.time, e.tp))

curr = 0
for e in events:
    if e.t == 1:
        curr += 1
    elif e.t == 2:
        print(curr)
    else:
        curr -= 1
```

Это решение работает, но в некоторых ситуациях может потеряться порядок запросов 

```python
class Event:
    def __init__(self, time, tp, idx) -> None:
        self.time = time
        self.tp = tp
        self.idx = idx


n = int(input())
events = []
k = 0
for i in range(n):
    tp, time = input().split()
    if tp == "+":
        new_tp = 1
    elif tp == "?":
        new_tp = 2
    else:
        new_tp = 3

    events.append(Event(int(time), new_tp, k))
    if new_tp == 2:
        k += 1

ans = [0 for i in range(k)]
events = sorted(events, key=lambda e: (e.time, e.tp))

curr = 0
for e in events:
    if e.t == 1:
        curr += 1
    elif e.t == 2:
        ans[e.idx] = curr
    else:
        curr -= 1

print(*ans)
```


Ещё иногда в качестве дополнительного поля может быть какая-то дополнительная информация, которая может довольно сильно усложнить обработку запросов 

Допустим, добавляется ещё уровень/ранг/допуск сотрудника

И получили такие события:
1. `+ t x` - в момент времени `t` пришёл сотрудник с уровнем x
2. `- t x` - в момент времени `t` ушёл сотрудник с уровнем x
3. `? t` - в момент времени `t` нужно узнать максимальный уровень допуска сотрудников

Один из возможных способов - использовать heap с тремя операциями: 
1. Добавить элемент
2. Удалить элемент
3. Найти максимальный элемент

Второй возможный вариант - дерево двоичного поиска, преимущество такого подхода - можем пытаться обнаружить какие-то некорректные запросы
Лучшие варианты деревьев - ==AVL== (если писать с нуля), ==RED AND BLACK TREE== (если не писать с нуля), ==TREAP== (если нужны будут более хитрые запросы)


Третий вариант - словарь. (Словарь на Python не подойдёт). Подойдёт словарь или множество, основанное на отсортированной структуре set/map в `cpp`, TreeSet/TreeMap в `Java`, sortedSet в `Python `
