# Целочисленный тернарный поиск
Постановка задачи будет примерно та же самая

Есть некая унимодальная функция, надо найти её максимум (или минимум). При этом функция определена только в целочисленных точках

Есть отрезок $[l; r]$, есть точка максиума

```
if f(m1) лучше f(m2)
    r = m2
else
    l = m1
```

## Оптимизация 1
В нецелочисленном бинарном поиске мы двигали границы ровно в точки m1, m2

В целочисленном тернарном поиске можно сдвигать границы:
r = m2 - 1
l = m1 + 1


## Оптимизация 2
Попробуем сделать так, чтобы поиск сходился быстрее

Мы можем взять m1 и m2 максимально близкие друг к другу, то есть, отличающиеся ровно на 1. Это позволит нам сделать центральную часть как можно меньше

## Оптимизация 3
Поменяем алгоритм выбора m1 и m2. Лучше всего их брать как:
```
while l < r:
    m1 = l + (r - l) // 2
    m2 = m1 + 1
    if f(m+1) better f(m2)
        r = m1
    else
        l = m2
```

Достаточно вести поиск, пока (l < r) 


## Докажем, что цикл, который мы написали, всегда завершается
Рассмотрим такие случаи: 
### `r = l + 1`

l и r - две соседние точки, в качестве m1 выбирается l, в качестве m2 выбирается r. В зависимости от того, где значение точки будет "лучше", получим либо r = m1 => l == r, либо l = m2 => l == r

### `r > l + 1`

m1 = l + (k // 2)
m2 = l + (k // 2) + 1

Тогда возможны два случая: 
- l = r + (k // 2) + 1 
  отбросили большую половину отрезка  
- r = l + (k // 2)
  отбросили k - (k // 2) <=> (k/2) округлённое вверх


**Следовательно**, граница каждый раз делится в два раза

```python
def f(x):
    return abs(x - 5) + 4


def find_best_x(l, r):
    while l < r:
        m1 = l + (r - l) // 2
        m2 = m1 + 1
        if f(m1) < f(m2):
            r = m1
        else:
            l = m2
    return l


if __name__ == "__main__":
    print(f(find_best_x(-10, 10)))
```

## Где может пригодиться целочисленный тернарный поиск
**Убывающая предельная полезность** - нужно выбрать предметы из какого-либо множества, у каждого из этих предметов есть какие-либо два параметра
*Например*, есть рюкзак, где предметы, у каждого из которого есть два параметра - вес и стоимость. Нужно набрать максимальную сумму

### Задача
Есть `m` предметов, у каждого два параметра: `wi` - вес предмета $w_{i} \in [1;2]$, `c_i` - стоимость предмета $c_{i} \in [0; 10^{9}]$. Нужно обрабатывать запросы:
В каждом запросе задаётся одно число `m_i`, надо найти максимальное по стоимости подмножество предметов с весом не больше `m_i`, то есть надо найти такой набор предметов из заданных 
Каждый запрос хотим обрабатывать за $O(\log n)$

| `w_i` | `c_i` |
| ----- | ----- |
| 1     | 5     |
| 1     | 3     |
| 1     | 3     |
| 2     | 8     |
| 2     | 9     |
| 1     | 6     |
| 2     | 12    |
| 2     | 5     |

Предположим, что мы точно знаем два предмета веса 1 и один предмета веса 2

#### Идея решения: 
Отсортируем эти предметы по убыванию стоимости в своём весе

`w_i=1`: 6 5 3 3
`w_i=2`: 12 9 8 5

Лучший вариант - брать первые два элемента для каждого веса. Будем строить префиксные суммы (для первого списка 0 6 11 14 17)

```python
def prefix_sum(a):
    n = len(a)
    p = [0 for i in range(n + 1)]
    for i in range(n):
        p[i + 1] = p[i] + a[i]
    return p

```

А что если нам нужно взять больше предметов, чем есть какого-то типа? Можно мысленно добавить нули в конец этого списка (из префиксных сумм достаточно брать последнюю)

Теперь можно перейти к тернарному поиску. Объявим функцию:
`f(x)` - стоимость лучшего набора предметов, если мы берём ровно `x` предметов веса 2

$$
f(x) = \text{сумма первых x предметов веса 2} + \text{сумма первых } (m_{i} - 2 x) \text{ предметов веса 1}
$$

Теперь f(x) легко вычисляется за $O(1)$

Количество предметов веса 2 $\left[ 0, \min\left( c_{2}, \frac{m_{i}}{2} \right) \right]$ где $c_{2}$ - количество предметов веса 2

$$
\begin{gathered}
g_{1}(k) - \text{сумма первых }k \text{ предметов весом } 1 \\
\end{gathered}
$$

$$
\begin{gathered}
g_{1}(x+1) - g_{1}(x) \leq g_{1}(x) - g_{1}(x-1) \\
g_{2}(x+1) - g_{2}(x) \leq g_{2}(x) - g_{2}(x-1)
\end{gathered}
$$

$$
f(x) = g_{2}(x) + g_{1}(m-2x)
$$
$$
f(x+1) = g_{2}(x + 1) +g_{1}(m - 2x - 2)
$$
$$
f(x-1) = g_{2}(x - 1) + g_{1}(m - 2x + 2)
$$


Докажем $f(x) - f(x-1) \geq f(x + 1) - f(x)$
Зачем? Это докажет, что функция унимодальная, а значит, её можно анализировать тернарным поиском

$$
\begin{gathered}
f(x) - f(x-1) \geq f(x+1) - f(x) \\
2f(x) \geq f(x+1) + f(x - 1) \\
2g_{2}(x) + 2g_{1}(m - 2x) \geq g_{2}(x + 1) + g_{2}(x - 1) + g_{1}(m-2x-2) + g_{1}(m - 2x + 2) \\
(g_{2}(x) - g_{2}(x - 1)) + (g_{1}(m - 2x) - g_{1}(m - 2x - 2)) \geq (g_{2}(x + 1) - g_{2}(x)) + g_{1}(m - 2x + 2) - g_{1}(m-  2x) \\
(g_{2}(x) - g_{2}(x-1)) \geq (g_{2}(x+1) - g_{2}(x)) \text{ (уже доказали) } \\
(g_{1}(m-2x) - g_{1}(m - 2x - 2)) \geq (g_{1}(m - 2x + 2) - g_{1}(m - 2x)) \text{ (по свойству } g_{1}\text{)} 
\end{gathered}
$$


# Как работать с тернарным поиском, если функция не унимодальная?
Хороший метод - разбить функцию на унимодальные отрезки и запускать тернарный поиск на этих отрезках и определить наибольшее/наименьшее значения среди полученных в результате разбиения
