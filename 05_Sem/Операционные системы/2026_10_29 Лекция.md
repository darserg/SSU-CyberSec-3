# Как работает память. Прикладной уровень
В самом простом отображении память рисуется как столбик или полоска, поделённая на ячейки - байты памяти
В данном столбике память будет выделяться для стэка и кучи по с разных сторон - стэк - заполняется сверху, куча - заполняется снизу

`0x800`

Для стандартной переменной `int a;` будет выделена область из нескольких ячеек памяти

Если описать функцию:
```c
void f() {
	int a;
	short b;
	// ...
	return 0;
}
```

Когда функция вызывается, под неё сразу же нужно выделить какое-то количество байт

Вообще память для вызова функций заканчивается тогда, когда заканчивается место под стэк и кучу

Когда вызывается рекурсия, то стэк начинает расти практически неограниченно и возникает ошибка StackOverflow - переполнение стэка


```c
void f() {
	int *a = malloc(9);
	for (i = 0..9) a[i] = i;
}
```

Для a выделяется 9 байт
