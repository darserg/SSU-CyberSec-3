Чем занимаемся на практиках

Базовая часть - восстановление пароля из хэша. Нужно будет написать программу, которая будет:
- запускаться, принимая параметры:
	- хэш
	- алфавит
	- длина



```bash
./pr <hash> <alph> <n>
```

принцип работы: 
проверяем все возможные комбинации из алфавита, состоящие из n букв
каждый пароль хэшируем и сравниваем с изначальным переданным паролем


весь последующий год мы будем дополнять эту нашу изначальную программу

создаём репозиторий, в нём создаём какой-то readme и дальше в pull request делаем задание до тех пор, пока не принят
